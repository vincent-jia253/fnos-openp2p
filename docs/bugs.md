**教训（写给下次）**：
- 用 `<` 重定向读**任何路径**之前，先确认它是常规文件且不是符号链接——FIFO/设备文件会让 shell 永久阻塞。
- `cmd 2>/dev/null | cmd2` 只抑制 `cmd2`；**重定向顺序**在管道里同样是纪律，不是风格。
- 数字型注入点/配置项要先做**格式与量级**校验，再做数值比较；否则畸形输入会让判据本身失效（比不校验更糟）。
- "写文件前解析符号链接"必须**同时**校验目标在允许范围内，否则解析等于给了逃逸通道。
